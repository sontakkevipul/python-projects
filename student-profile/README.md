# 🎓 Student Profile Management

A Python-based student profile management program that stores and processes student, course, batch, and skill information.

## 📌 Features

- Student profile management
- Course and batch mapping
- Completed skill tracking
- Progress calculation
- Enrollment information
- Attendance and status display

## 🛠️ Python Concepts Used

- Lists
- Tuples
- Dictionaries
- Nested dictionaries
- Loops
- Conditional statements
- String formatting
- Basic calculations

## ▶️ How to Run

Make sure Python 3 is installed.

```bash
python student_profile.py
