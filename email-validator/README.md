# 📧 Email Validator

A Python-based email validation program that performs basic validation checks using string operations and conditional logic.

## 📌 Validation Rules

The email must:

- Contain `@`
- Contain exactly one `@`
- Have a username of maximum 15 characters
- Contain `.`
- Not contain spaces

## 🛠️ Python Concepts Used

- Strings
- `count()`
- `split()`
- Conditional statements
- Boolean expressions
- User input
- Basic validation

## ▶️ How to Run

Make sure Python 3 is installed.

```bash
python email_validator.py
