# 📊 CSV Employee Record Management

A Python-based employee record management application that stores employee information in a CSV file.

## 📌 Features

- ➕ Add employee records
- 📋 View employee records
- 🔎 Search employee by ID
- 💾 Store records in CSV format
- 📖 Read records from CSV
- ⚠️ File-not-found handling
- 🔄 Multiple operations in a single session
- 📋 Menu-driven interface

## 🛠️ Python Concepts Used

- CSV module
- File handling
- `open()`
- `csv.reader()`
- `csv.writer()`
- `with` statement
- `try-except`
- Lists
- Loops
- Conditional statements
- User input
