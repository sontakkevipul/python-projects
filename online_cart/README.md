# 🛒 Online Shopping Cart

A Python-based shopping cart program that allows users to add, remove, search, and view items in a shopping cart.

## 📌 Features

- Add items to the cart
- Remove items from the cart
- Search for items
- View all items in the cart
- Handles items that are not available

## 🛠️ Python Concepts Used

- Lists
- `append()`
- `remove()`
- Membership operator `in`
- `for` loop
- User input
- Conditional statements

## ▶️ How to Run

Make sure Python 3 is installed.

```bash
python online_cart.py
