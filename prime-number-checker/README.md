# 🔢 Prime Number Checker

A simple Python program that checks whether a given number is a prime number.

## 📌 Features

- Accepts a number from the user
- Checks whether the number is greater than 1
- Checks divisibility using the modulus operator
- Displays whether the number is prime or not

## 🛠️ Python Concepts Used

- Variables
- User input
- `if / else`
- `for` loop
- `range()`
- Modulus operator `%`
- Boolean variables
- `break`

## ▶️ How to Run

Make sure Python 3 is installed.

```bash
python prime_checker.py
