# 👨‍💼 Employee Record Management

A Python-based employee record management program that allows users to add, view, and search employee records through a menu-driven interface.

## 📌 Features

- ➕ Add employee records
- 📋 View all employee records
- 🔎 Search employee by ID
- 🗂️ Store employee information using dictionaries
- 🔄 Multiple operations in a single session
- 🚪 Exit option
- 📋 Menu-driven interface

## 🛠️ Python Concepts Used

- Variables
- Lists
- Dictionaries
- Nested data structures
- `while` loop
- `for` loop
- `if-elif-else`
- `break` statement
- Boolean variables
- User input
- Searching records
