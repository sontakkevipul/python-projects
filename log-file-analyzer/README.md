# 📋 Linux Log File Analyzer

A Python-based log analysis tool that reads an application log file and counts `ERROR`, `WARNING`, and `INFO` messages.

## 📌 Features

- 📖 Reads application log files
- 🔴 Counts ERROR messages
- 🟡 Counts WARNING messages
- 🔵 Counts INFO messages
- ⚠️ Handles missing log files
- 📊 Displays a simple log summary

## 🛠️ Python Concepts Used

- File handling
- `open()`
- `with` statement
- `for` loop
- `if-elif-else`
- String searching using `in`
- Counters
- `try-except`
- Exception handling
