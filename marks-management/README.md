# 📚 Marks Management

A Python-based marks management program that calculates subject-wise and total marks using nested dictionaries and loops.

## 📌 Features

- Stores marks for multiple subjects
- Separates internal and external marks
- Calculates subject-wise total
- Calculates overall marks
- Displays results clearly

## 🛠️ Python Concepts Used

- Dictionaries
- Nested Dictionaries
- `for` loop
- `.items()`
- Variables
- Arithmetic operations
- Print statements
