# 🔐 Password Validator

A Python-based password validation program that checks whether a password meets defined security requirements.

## 📌 Validation Rules

The password must:

- Contain **8 to 15 characters**
- Have at least **one uppercase letter**
- Have at least **one lowercase letter**
- Have at least **one digit**
- Have at least **one special character**

## 🛠️ Python Concepts Used

- Strings
- `for` loop
- `if / elif / else`
- `isupper()`
- `islower()`
- `isdigit()`
- Boolean variables
- Input validation
- Conditional expressions
